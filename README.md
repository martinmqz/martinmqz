## Hi there! 👋
I'm Martin, a senior full-stack engineer with 12+ years of experience. Most recently I owned payments, invoicing, and financial integrations end to end for a multi-tenant SaaS: idempotent webhook pipelines, fail-closed money math, and the React/React Native interfaces on top.

I work backend to frontend in **TypeScript and .NET**: API and data-model design, third-party integrations (Finix, Wisetack, QuickBooks, Plaid), and accessible, performant UI in React and Next.js. I also build **AI-first**: agentic coding tools (Codex, Claude Code) are part of my daily workflow, and I've built my own tooling around them, including a local-first RAG platform for codebase Q&A and a review-intelligence system that turns past code-review findings into targeted checks for new work.

Open to senior full-stack and AI-native roles. [Reach out](mailto:martin@webect.com), connect on [LinkedIn](https://www.linkedin.com/in/webect/), or see my [portfolio](https://martinmqz.github.io).
